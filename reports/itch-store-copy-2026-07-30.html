Nothing to install. The Far Carry runs in your browser, on desktop or phone — press Run game and play. Fullscreen is where it looks best; it is designed portrait-first, so it works properly on a phone.

Your progress is saved on your own device, in this browser, with no account and nothing sent anywhere. That means two things worth knowing:

  • Back it up. Settings → Save data → Export writes one file holding every campaign, your current run and your settings. Import restores it — on any device, in any browser.
  • Clearing site data erases it. Private/incognito windows, and browsers that block third-party storage, can stop the game saving at all. If writes are not sticking, the title screen says so rather than letting you find out later.

Saves do not travel between where you play. A save made here lives with this page; the export file is the bridge.

To play offline — and to get the sturdiest save — open the game at farcarry.vulpecula.games and install it:

  • Android (Chrome) — let the page finish loading, then menu ⋮ → Install app. It installs as a real app, so it lands in your app drawer rather than on your home screen; drag it across from there if you want it on the front page.
  • iPhone / iPad — open it in Safari, then Share → Add to Home Screen. It has to be Safari; installing from another browser on iOS gives you a bookmark, not an app.
  • Desktop — Chrome or Edge show an install icon in the address bar.

Installed, it runs with no connection at all and the browser stops treating your progress as disposable. (An app cannot be installed from inside an embedded page, which is why that link is outside this one.)

Playing & saving

Runs in the browser — desktop or phone, no install, no account. Pull back to load the swing and release, or play the whole game from the keyboard (← → aim, ↑ ↓ power, Shift for fine steps). Readable-text scaling, reduced motion, screen-reader narration and left-handed control mirroring are all in Settings.

Progress saves to your own device and never leaves it. Export a backup from Settings → Save data — one file with every campaign, your run and your settings, importable anywhere. Clearing your browser's site data will erase the save, and some private-browsing modes block saving outright (the title screen tells you if that is happening, rather than letting you lose a campaign to it).

For offline play and the most durable save, install it from farcarry.vulpecula.games — same game, same build, running as its own app with no connection needed. On Android use Chrome's ⋮ → Install app; on iPhone use Safari's Share → Add to Home Screen.
